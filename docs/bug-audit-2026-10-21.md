# 代码审计 — 定位 / 逻辑缺陷清单（2026-10-21）

范围：`client/src`（subtitle-multilang、channel-basic、selectors、page-detector、
navigation、dom-service、task-runner）+ `scripts/security-audit.sh`。
依据：SPEC §3–§14、§15–22、§34–42；IMPLEMENTATION §9–11、§39–44；
`docs/studio-dom-calibration.md`（Layout A/B 证据包）。

## 0. 基线状态（本机实测）

| 命令 | 结果 |
| --- | --- |
| `pnpm test` | 25 文件 / 202 用例全通过 |
| `pnpm typecheck` | 无错误 |
| `pnpm build` | `client/dist/Luftballons.user.js` 218.66 kB 构建成功 |
| `./scripts/security-audit.sh` | 报 FAILED，但根因是环境无 `rg`（ripgrep） |

环境注记：沙箱下 pnpm 需重定向 `XDG_DATA_HOME/XDG_RUNTIME_DIR` 到 /tmp 才能运行。

**审计脚本缺陷（P1）**：`scripts/security-audit.sh` 的 `rg_fixed`/`rg_regex` 对
`rg` 缺失静默吞错（`|| true`），即工具缺失时所有安全检查“空跑通过”（fail-open），
仅 `const_keys` 检查因结果为空而失败。修法：启动时检测 `rg`，缺失即 fail-closed
（或回退 `grep -P`）。

**测试盲区（根因级）**：fixture 会写入生产代码永远不产生的标记
（`data-luftballons-captions-ready`、`data-subtitle-list-state`、
`data-subtitle-state`，见 `client/tests/fixtures/studio-simulated.ts:463/626/642`），
且 fixture 全为轻 DOM。因此 202 个用例验证的是“自证式路径”，无法发现真机
标定错误、shadow DOM 失配、语言映射缺口 —— 与“测试全绿但真机很多 Bug”一致。

## 1. P0 — 高置信缺陷（逻辑明确错误 / 违反 SPEC）

字幕流程（youtube.subtitle.multilang）：

1. **单语言失败即中止整条队列且状态错误** —
   `client/src/sites/youtube-studio/modules/subtitle-multilang/workflow.ts:2432-2444`。
   任一语言出错 → 后续全部 CANCELLED + `return FAILED`，即使前面已有 SUCCESS/已发布。
   违反 SPEC §37「单语言失败不必导致所有语言失败」，与同文件 buildResult（失败+成功→PARTIAL，
   `workflow.ts:2017-2022`）自相矛盾。修：失败仅记该语言 FAILED 并 continue，收尾走 buildResult。
2. **盲目 catch 后在页面级兜底点击「手动字幕→添加」** — `workflow.ts:2297-2308、2326-2337`。
   吞掉一切错误（含 assertBinding 的 VIDEO_SWITCHED），随后点任意 manual 添加按钮
   （可能属于其它语言/残留对话框）。违反 SPEC §3.4。修：仅“控件确实不可见”且语言绑定
   校验通过才兜底；绑定失败/切视频直接抛出。
3. **editorLanguageBinding 判定错误** — `workflow.ts:1168-1175`（`every()` 分支是死代码，
   只要含目标 code 即 match，mismatch 检测被架空）+ `workflow.ts:1178-1215`
   （`hay.includes(alias)` 子串匹配，两字母 code 别名 en/es/ar/de 会命中 Content/Settings
   等普通词 → 错语言放行或误拒）。修：要求 codes 全为 want；别名用词边界匹配并剔除 ≤2 字符 code。
4. **manual_dialog 不做语言绑定** — `workflow.ts:888-933`。存在「手动字幕 添加」即返回
   manual_dialog 并继续 自动翻译→发布，未验证卡片属于目标语言。修：须
   `editorLanguageBinding(宿主, lang)==="match"`。
5. **Human Gate 拒绝却返回 COMPLETED** — `workflow.ts:1985-1998`。修：humanRejected → CANCELLED。
6. **表头行过滤正则对中文永不生效** — `workflow.ts:417` `/^语言\b/`。
   已验证 `/^语言\b/.test("语言")===false`（中文非 \w，\b 不成立）；表头「语言 音频 字幕」
   会作为数据行进入解析 → 列表 UNPARSEABLE → 整任务失败。修：trim 后 `=== "语言"` 或
   中文安全边界。
7. **空语言列表在真机永远无法确认** — `workflow.ts:555-560`（hasConfirmedEmptyList 只认
   fixture 属性 `data-subtitle-list-state="EMPTY"`，注释自认未标定）+ `workflow.ts:562-585`
   → EMPTY 一律 UNPARSEABLE → “给无字幕视频添加语言”必失败。修：标定真实空态信号。

采集流程（youtube.channel.basic）：

8. **中途非取消异常丢弃已采数据（缺 fail-partial）** —
   `client/src/sites/youtube-studio/modules/channel-basic/collector.ts:608-617` +
   `module.ts:79-84`。NavigationError/保存失败等非 abort 错误直接 throw → 数据全丢。
   违反 SPEC §19 / P3-T3。修：非 abort 错误也 persistPartial。
9. **DASHBOARD 导航回落含永不匹配的占位符** — `client/src/sites/youtube-studio/selectors.ts:143`
   字面 `a[href="/channel/__runtime_channel_id__"]`（已核实全仓库无替换逻辑）+
   `selectors.ts:545-553` + `navigation.ts:206-216`：从 `/video/{id}/…` 页触发采集时
   channelId 提取为 null → 必然 NO_ANCHOR → 任务失败。修：从抽屉锚点
   `ytcp-navigation-drawer a[href^="/channel/"]` 推导 channelId，或跳过 Dashboard 步骤。
10. **采集全程无状态提示** — collector.ts 无一处 `ctx.setProgress`（对照 subtitle 每步都有）。
    违反 SPEC §40。修：各阶段 setProgress。
11. **内容列表「就绪」判定过严** — `collector.ts:505-514`：要求所有行 title+views 均可解析
    才算就绪；任一行缺 views（排程/直播/其它布局）→ 永不就绪 → 必然 CONTENT_LOAD_TIMEOUT。
    修：就绪=列表出现且行稳定；解析失败逐行 VIDEO_SKIPPED。
12. **占位符「—」当解析失败 + 任意 warning 强制 PARTIAL** — `collector.ts:128-137、263-267`
    （已核实 `blockingWarnings = warnings.some(w => w.code !== "METRIC_DISPLAY_ROUNDED")`）。
    em dash 语义是“未显示此值”而非坏数据；占位符比“元素缺失”待遇更差。
    修：placeholder 独立处理；PARTIAL 以最终字段缺失为准。

基础设施（services/runtime）：

13. **DomService 解析不进 shadow root** — `client/src/services/dom-service.ts:227、255`
    用普通 `querySelectorAll`；`querySelectorAllDeep`（188-213）只被 workflow 内部使用。
    Studio 是 web component 重度站点，shadow 内控件 find/waitFor/click 静默失配。
    修：resolveDomTarget / waitForDomTarget 统一走 deep 查询（含 observer 覆盖 shadow）。
14. **unique 歧义时“降级到更宽回退选择器”而非失败** — `dom-service.ts:176-183、250-265`，
    与自身注释及 SPEC §3.4 相悖（歧义应拒绝）。修：unique 目标任一阶段歧义即 null，不降级。

## 2. P1 — 需真机验证（逻辑问题已可指出）

字幕：
- Layout B 频道级 `/channel/{id}/translations` 与 recheckVideoBinding（必须 /video/{id}）
  及 `subtitlesNavTarget`（只找 /video/{id}/translations）根本不兼容
  — `workflow.ts:86-135`、`selectors.ts:101-114`。Layout B 下必 NO_ANCHOR/绑定失败。
- actionDomForLanguage 点击自动翻译前一次性定根，编辑器重渲染后全部失配
  — `workflow.ts:1762-1798`。修：每次查找前重解析根。
- waitForPublishedRow 列表瞬时卸载即判失败 — `workflow.ts:656-683`。
- 残留「无法发布空白字幕」toast 毒化后续语言（全文档、无语言/时间限定，且为 ERROR 首判）
  — `workflow.ts:1654-1656、1744-1748`。
- publishVerifyOk 要求“全文档无活动编辑器”，且裸 document 未排除 SPA 保留页
  — `workflow.ts:619-626、642-644、1218-1228`。
- READY 判定过宽（任意 ≥2 字符文本即 cue 证据，排除词仅 5 个）— `workflow.ts:1541-1582`；
  `subtitle.captions.ready` 目标同样过宽且无人使用（`selectors.ts:457-486`，死配置）。
- 语言标签映射缺口：`schema.ts:140-168` 仅 9 种语言；任一已存在行标签未映射
  （意大利语/俄语/越南语/日文 Japanese/…）→ 整个列表 UNPARSEABLE → 整任务失败
  （`workflow.ts:497-506`）。`labelAliasesForLanguage` 无 zh-Hant 分支（schema.ts:215-217）。
- 选项匹配 `test-id===code` 精确相等 + 筛选框固定输中文名 + 3s 盲滚
  — `workflow.ts:729-735、790-808`、`schema.ts:225-239`。
- 脆选择器：`selectors.ts:252` `ariaLabel:"翻译"` 精确匹配且语义分支优先于已标定 CSS 回退
  （真机是「可滚动的翻译」）；`selectors.ts:335` picker 判定裸 `语` 匹配任何含“语”容器。

采集：
- 分页范围正则只认「第 X-Y 条，共 Z 条」+ ASCII 连字符（`collector.ts:536`）；
  校准记录的是「1–1 of 1」en dash 格式 → 永远 VIDEO_SCOPE_PARTIAL。
- 分页 disabled 要求 disabled && aria-disabled 同时成立（`collector.ts:535`）。
- 排序探针限定在 `list.querySelector(...)`（`collector.ts:530`），表头在列表外则永远读不到。
- Dashboard/Analytics 指标一次性 readText，无状态等待（`collector.ts:413-432、456-460`）。
- Dashboard views 选择器依赖 `#metric-0-value` 序号（`selectors.ts:218-220`）。
- 频道名 directText 启发式（`collector.ts:391、194-198`）名称包 span 即空。
- videoId 正则只匹配相对 href（`collector.ts:170`）。
- 负号不认 U+2212（`metrics.ts:23-31`）；CJK 万/亿不解析（`metrics.ts:25-26`，
  已知缺口但认证环境即中文站）。
- Analytics 采纳条件要求 period label + dates 齐备（`collector.ts:463-474`），严于校准文档。
- 导航锚点精确 href 匹配（`selectors.ts:121-132`）带 query/绝对 URL 即失配。
- 页面判定取“第一个” aria-current，postcondition 强依赖 DOM 判定
  （`page-detector.ts:109-114`、`navigation.ts:96-98`）→ waitReady 假超时。
- `page.video_details.title` 未校准（`selectors.ts:182-187`）→ waitReady("VIDEO_DETAILS") 必超时。
- zh 专属标定（`selectors.ts:215-220`「摘要/观看次数」、`subtitle.add_language`/`subtitle.publish`
  精确中文文本）在非中文界面失效（fail-closed，但功能不可用）。
